# GHBIO Co-Scientist

scRNA-seq bioinformatics workbench for VS Code / code-server.

## 프로젝트 정보 (Project info)

- 📜 [**BioIDE 헌장 (Central Dogma · Constitution)**](MISSION.md) — 모든 재현 튜토리얼이 지켜야 할 헌법.
  핵심: *저자의 라벨·주석을 소비하지 말고, 새로 짠 GPU·Python 코드로 처음부터 다시 도출해 검증하라.*
  단일 원본은 `src/mission.ts`이며, "파이프라인 만들기" 패널과 모든 AI 설계 프롬프트에 자동 노출·주입됩니다.
- 📄 [이 튜토리얼은 어떻게 만들어졌는가](<how this tutorial is made.md>) — 췌장암 PDAC 파이프라인이
  AI 초안 → 환각 검토 → 실제 데이터 검증 → 재작성 → 실행 검증 → 배포까지 거친 전 과정과,
  *"소스코드 없이 어떻게 논문 워크플로를 재현했는가"* 에 대한 정직한 방법론 설명.
